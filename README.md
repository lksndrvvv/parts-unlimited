# parts-unlimited
Практическая 3 — Программная инженерия. 
Управление календарем и графиками поставок решений.

## Цель работы
Организовать календарное планирование поставок программного продукта для нескольких рабочих команд, выявить зависимости между задачами и скорректировать сроки выполнения работ.

## Используемые инструменты
- GitHub Repository
- GitHub Issues
- GitHub Projects
- GitHub Roadmap
- GitHub Milestones

## Команды
1. Parts Unlimited Team — разработка веб-приложения.
2. External integrations — интеграции с внешними сервисами и корпоративными данными.

## План поставки
Поставка Веб-приложения.

## Задачи
- Настроить беклог и спринты.
- Создать календарный план.
- Настроить фильтрацию завершенных задач.
- Добавить контрольную дату.
- Спланировать работу нескольких команд.
- Выявить зависимости между задачами.
- Перенести работы для устранения конфликта сроков.

## Результат
Планирование поставки программного продукта реализовано средствами бесплатного GitHub вместо Azure DevOps.
