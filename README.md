# parts-unlimited
Практическая 3 — Программная инженерия. 
Управление календарем и графиками поставок решений.

## Цель работы

Научиться планировать задачи проекта, распределять их между командами и управлять сроками выполнения работ.

## Ход работы

Для выполнения практической работы использовалась бесплатная платформа GitHub вместо Microsoft Azure DevOps.

1. Создан репозиторий `parts-unlimited` и проект для управления задачами.
2. В GitHub Issues добавлены 9 задач по разработке веб-приложения и интеграции с внешними сервисами.
3. В GitHub Projects настроены статусы задач, спринты, итерации и даты выполнения.
4. Задачи распределены между двумя командами: Parts Unlimited Team и External integrations.
5. Создан календарный план «Поставка Веб-приложения» с помощью Roadmap.
6. Настроена фильтрация завершённых задач и добавлена контрольная дата «Команда в отпуске» — 30.10.2026.
7. Для команды External integrations созданы Итерация 50 и Итерация 51.
8. При анализе плана выявлена зависимость между задачами по интеграции данных доставок и отслеживанию посылок.
9. Для согласования сроков задачи перераспределены между спринтами и итерациями.

## Результат

В GitHub создан календарный план проекта с двумя командами, задачами и сроками их выполнения. После анализа зависимостей график поставок был скорректирован.

## Вывод

В ходе практической работы были изучены способы планирования задач и управления графиками поставок. Основные функции Azure DevOps удалось заменить бесплатными инструментами GitHub: Issues, Projects, Roadmap и Milestones.
